# AI 五子棋游戏应用 - PRD

## 1. 项目信息
- **项目名称**: AI Gomoku
- **技术栈**: 后端 Python + FastAPI；前端 Vite + React + Tailwind CSS
- **棋盘**: 15×15 标准五子棋
- **原始需求复述**: 开发一个支持多模型配置、多AI玩家、人机/观战模式、房间制的 Web 五子棋应用，AI 决策通过大模型接口完成。

## 2. 产品目标
1. 让用户能快速配置任意 OpenAI 兼容大模型，并用它们驱动 AI 玩家对战。
2. 提供清晰的房间制对战体验：人机对战与 AI 观战双模式。
3. 在牌桌上直观展示棋盘、落子日志与 AI 思考过程。

## 3. 用户故事
- 作为普通用户，我可以创建房间、选择模式（人机/观战）、选择 AI 玩家并开始对局。
- 作为配置者，我可以添加/编辑/删除模型配置、测试连通性、拉取可用模型列表、管理 AI 玩家。
- 作为观战者，我可以进入观战房间观看两 AI 自动对弈，并看到每一步的决策理由。

## 4. 需求池

### P0（必须有）
- 模型配置 CRUD + 连通性测试 + 拉取模型列表
- AI 玩家 CRUD（绑定模型）
- 房间创建 + 满员自动开始
- 人机模式与观战模式
- 15×15 棋盘落子、回合流转、胜负判定
- AI 通过 LLM 决策，含合法性校验与兜底策略
- 牌桌 UI：棋盘、双方棋子、AI 思考日志
- 响应式布局

### P1（应该有）
- 积分/战绩记录
- 对局历史回放
- 提示词模板可配置
- 棋盘坐标标注与落子动画

### P2（可以有）
- 难度选择（控制温度/top_p）
- 音效与主题切换
- 多房间并发支持

## 5. UI 原型描述
- **首页/房间列表**: 创建房间入口、房间列表、当前对局状态
- **配置页**: 模型配置表单（名称、Base URL、API Key、测试按钮、模型列表下拉）、AI 玩家列表
- **对局页**: 左侧/顶部棋盘（响应式），右侧/底部日志面板显示 AI 思考过程；观战模式隐藏操作区
- **结算弹层**: 胜负提示、积分变更

## 6. 待确认问题
1. 是否需要用户账号体系？（建议 v1 先本地存储）
2. 是否要求特定模型提供商优先？（建议通用 OpenAI 兼容格式）
3. 落子超时时间默认多少？（建议 30s）
4. 是否支持禁手规则？（建议 v1 无禁手，自由规则）
5. 积分规则细节？（建议胜 +1，负 -1，观战不计）

## 7. 成功指标
- 模型配置到 AI 落子端到端可用
- 同一页面可同时承载人机与观战两种模式
- 移动端棋盘可用性与桌面端一致
